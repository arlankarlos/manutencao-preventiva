🚀 Sobre o projeto

O Manutenção Preventiva é um webapp desenvolvido para profissionais que trabalham com serviços recorrentes e precisam organizar atendimentos, controlar prazos e manter contato com clientes de forma eficiente.

💡 O sistema transforma serviços pontuais em receita recorrente previsível.

Inicialmente focado em ar-condicionado, mas projetado para atender qualquer tipo de manutenção:

- ❄️ Climatização
- ⚡ Elétrica
- 🚿 Hidráulica
- 🚗 Automotiva
- 🏢 Predial
- 🖥️ Equipamentos

---

⚙️ Funcionalidades

📋 Cadastro de clientes

- Nome, telefone (WhatsApp) e endereço
- Múltiplos equipamentos por cliente
- Quantidade + modelo/descrição

---

🔁 Agendamento recorrente

- Definição da última visita
- Intervalo configurável:
  - Semanas
  - Meses
- Cálculo automático da próxima manutenção

---

⏰ Sistema de alertas

- Status automático:
  - 🔴 Atrasado
  - 🟡 Hoje
  - 🟢 Próximo
- Ordenação inteligente por prioridade

---

💬 Integração com WhatsApp

- Mensagem automática pronta
- Variáveis dinâmicas:
  - "{nome}"
  - "{data}"
  - "{endereco}"
  - "{aparelhos}"
  - "{tecnico}"

Ações rápidas:

- 📋 Copiar mensagem
- 📲 Abrir conversa no WhatsApp

---

✏️ Personalização de mensagens

- Template editável
- Padrão otimizado
- Preparado para automação

---

🔄 Reagendamento automático

- Um clique após atendimento
- Próxima visita gerada automaticamente

---

💾 Persistência local (MVP)

- Armazenamento via LocalStorage
- Sem backend (rápido e leve)

---

🧠 Diferencial

Este sistema não é apenas um cadastro de clientes.

Ele foi projetado para:

- 📈 Aumentar faturamento recorrente
- 🔁 Criar previsibilidade de serviços
- 📉 Reduzir esquecimentos
- 🤝 Melhorar relacionamento com clientes

📦 Instalação

# Clone o repositório
git clone https://github.com/seu-usuario/manutencao-preventiva.git

# Acesse a pasta
cd manutencao-preventiva

# Instale as dependências
npm install

# Rode o projeto
npm run dev
